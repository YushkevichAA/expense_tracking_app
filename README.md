## Запуск проекта

Для запуска необходимы Node.js ^24 и npm ^11. В качестве базы данных используется SQLite.

### 1. Клонирование репозитория

```bash
git clone https://github.com/YushkevichAA/expense_tracking_app.git
cd expense_tracking_app
```

### 2. Установка зависимостей

Выполните из корня проекта:

```bash
npm install --prefix ./backend
npm install --prefix ./frontend
```

### 3. Настройка переменных окружения

Создайте файл окружения:

```bash
cp backend/.env.example backend/.env
```

Замените содержимое `backend/.env`:

```dotenv
PORT=3001
DB_PATH=database.sqlite
MODE=development
```

При запуске сервера файл базы данных `database.sqlite` будет создан в каталоге `backend`. Значение `MODE=development` включает автоматическое создание и синхронизацию таблиц через TypeORM.

> Автоматическая синхронизация предназначена для локальной разработки. Для рабочей среды необходимо подготовить миграции и отключить режим `development`.

### 4. Запуск серверной части

В первом терминале из корня проекта выполните:

```bash
cd backend
npm run start:dev
```

Сервер доступен по адресу: http://localhost:3001.

### 5. Запуск клиентской части

Во втором терминале из корня проекта выполните:

```bash
cd frontend
npm run dev -- --port 5173 --strictPort
```

Откройте приложение в браузере: http://localhost:5173.

Запросы клиента с префиксом `/api` перенаправляются прокси-сервером Vite на `http://localhost:3001`. При перенаправлении префикс `/api` удаляется.

> Маршрут `/api/health` в текущей версии не реализован.

### 6. Остановка приложения

Нажмите `Ctrl+C` в терминалах серверной и клиентской частей.
