## Description

MVP серверная часть приложения

## Project setup

Для запуска серверной части должно быть установлено node ^24 версии и npm ^11

Установите зависимости проекта командой

```bash
$ npm install
```

Создайте файл db.sqlite и разместите его в какой-либо папке, например data

Добавьте в корень проекта файл .env и укажите переменные окружения согласно структуре .env.example

в переменной DB_PATH укажите путь до файла db.sqlite относительно корня приложения или абсолютный путь

## Compile and run the project

запустите приложение в демонстрационном режиме

```bash
# watch mode
$ npm run start:dev
```
